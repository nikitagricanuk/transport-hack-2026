# Сравнение с PTV Visum и PTV Vissim

Дата: 11.11.2026. Сравнение по публичной документации PTV и возможностям редактора в ветке `main`.

## Кто что делает

| | PTV Visum | PTV Vissim | Наш редактор УДС |
|---|---|---|---|
| Уровень | Макромодель города или региона | Микромодель перекрёстка или коридора | Подготовка и проверка графа OSM, экспресс-аналитика |
| Главный результат | Матрицы корреспонденций, нагрузка сети, работа ОТ | Поведение каждой машины и пешехода, очереди, задержки | Исправленный `.osm`, который загружается в MATSim, SUMO и Webots |
| Вход | Собственная сеть, районы, матрицы, расписания, GTFS | Детальная геометрия полос, светофорные программы, составы потока | Любой `.osm` |
| Цена и доступ | Платная лицензия, Windows | Платная лицензия, Windows | Бесплатно, работает в браузере, совместная работа |

PTV делает инструменты моделирования. Наш редактор готовит для моделирования корректную сеть: находит ошибки графа, предлагает исправления и проверяет файл по российским нормам. С Visum и Vissim он не конкурирует, а встаёт перед ними в цепочке.

## Что у нас уже есть

- **Проверка графа:** связность, направления, полосы, повороты, мосты и уклоны. Исправления с превью, которые применяет человек. Ни в Visum, ни в Vissim такой проверки сырого OSM нет.
- **Нормы РФ:** уровень обслуживания по ОДМ 218.2.020-2012, категории улиц по СП 42.13330, скорости по ПДД, уклоны по СП 42.
- **Статическая нагрузка:** интенсивность и пропускная способность, z = q/c, задержки по функции BPR, учёт g/C светофора, перекрытия с объездами, снимки «до / после».
- **Новое: состав потока.** Шесть типов транспорта с коэффициентами приведения по СП 34.13330.2021, табл. 5.3. Коэффициенты можно менять.
- **Сетевой анализ:** маршрут, изохроны, пешеходная доступность остановок, доступность на ОТ.
- **Новое: анализ остановок.** Покрытие жилья в радиусе 500 м по СП 42, зоны и районы с нехваткой остановок, загруженность остановок, советы.
- **Симуляция:** SUMO запускается прямо в редакторе, анимацию можно смотреть на карте и в 3D.
- **Отчёты:** Word, Excel и PDF с формулами. Совместное редактирование и история правок.

## Чего не хватает по сравнению с Visum

| Возможность Visum | У нас | Что сделать | Приоритет |
|---|---|---|---|
| Транспортные районы, коннекторы, матрицы корреспонденций | Только оценка OD по сетке | Районы из `landuse`/`place` или полигонов пользователя; импорт и экспорт матриц в CSV | Высокий |
| Четырёхшаговая модель: генерация, распределение (гравитационная модель), выбор способа, распределение по сети | Нагрузка задаётся по классу дороги или вручную | Генерация от жителей (уже считаем по зданиям) и мест приложения труда; гравитационное распределение; равновесное распределение по сети (Франк — Вульф) вместо фиксированной доли пропускной способности | Высокий |
| Распределение пассажиров ОТ по расписанию: пересадки, ожидание, наполняемость рейсов | Частота маршрутов и оценка загрузки остановки | Нагрузка на перегонах маршрутов (пасс./ч), наполняемость рейсов, импорт GTFS | Высокий |
| Расчёт по времени суток (динамика спроса) | Множители «утро / день / вечер / ночь» | Профиль спроса по часам, расчёт на 24 ч | Средний |
| Показатели работы ОТ: пробег, рейсы, потребность в подвижном составе, стоимость | Нет | Пробег и число машин из интервала и длины маршрута | Средний |
| Менеджер сценариев | Снимки нагрузки | Именованные сценарии, в которых меняются и граф, и спрос, и светофоры; сравнение любой пары | Средний |
| Пучки потоков (flow bundle): откуда идут машины через выбранное ребро | Нет | Показать маршруты, проходящие через ребро, после распределения по сети | Средний |
| Скрипты Python и COM API | REST API без документации | Опубликовать OpenAPI и примеры сценариев на Python | Низкий |

## Чего не хватает по сравнению с Vissim

| Возможность Vissim | У нас | Что сделать | Приоритет |
|---|---|---|---|
| Типы и классы транспорта с распределениями скорости, ускорения и длины | Состав потока с коэффициентами только в статическом расчёте | Передавать состав в SUMO как `vType` (passenger, bicycle, truck, bus) с долями из таблицы | Высокий |
| Модели следования и перестроения (Wiedemann 74/99), калибровка | Стандартный SUMO (Krauss) | Выбор модели SUMO (IDM, Krauss) и параметров в настройках симуляции | Средний |
| Светофорные программы: жёсткие, адаптивные, VAP/RBC, ring-barrier | Двухфазный план g/C | Многофазные программы, промежуточные такты, передача программы в SUMO `tlLogic` | Высокий |
| Конфликтные зоны и правила приоритета | Правила SUMO по умолчанию | Знаки приоритета из OSM (`highway=give_way/stop`) проверять и передавать в сеть | Средний |
| Остановки ОТ: время стоянки, посадка и высадка | Загруженность остановки по оценке | Время стоянки из спроса остановки; карманы и остановки на полосе | Средний |
| Пешеходы (Viswalk, Social Force) | Пешеходная доступность по графу | Пешеходы SUMO (`--pedestrian.model striping`) на переходах | Низкий |
| Метрики узлов и участков: очереди, задержки, остановки, уровень обслуживания по HCM | Время в пути и число машин из SUMO | Detectors SUMO (E2/E3) и отчёт по очередям на подходах к светофорам | Высокий |
| Выбросы и шум | Нет | Модель выбросов HBEFA в SUMO и отчёт по CO₂ и NOₓ | Низкий |
| Калибровка по данным счётчиков (GEH) | Ручной ввод интенсивности | Импорт подсчётов, критерий GEH, подгонка спроса | Средний |

## Что улучшить в первую очередь

1. **Спрос вместо оценки по классу дороги.** Районы, генерация от жителей и мест работы, гравитационная модель и равновесное распределение. От этого зависят все остальные числа в аналитике.
2. **Состав потока в симуляции.** Типы транспорта из новой таблицы передавать в SUMO как `vType`, чтобы статический расчёт и симуляция использовали один состав.
3. **Пассажиропоток ОТ.** Нагрузка на перегонах и наполняемость рейсов, импорт GTFS. Тогда загруженность остановок будет считаться по маршрутам, а не по оценке в радиусе.
4. **Светофоры.** Многофазные программы и выгрузка в SUMO, отчёт по очередям на подходах.
5. **Калибровка.** Импорт подсчётов и критерий GEH, чтобы сравнивать модель с реальностью.

## Где мы сильнее

- Исправление сырого OSM с превью и проверкой после каждой правки: PTV исходит из того, что сеть уже чистая.
- Работа в браузере без установки и лицензии, совместное редактирование.
- Проверки по российским нормам (ОДМ, СП 42, СП 34, ПДД) и подстановка формул в отчётах.
- Один исправленный файл подходит сразу для трёх симуляторов: MATSim, SUMO и Webots.
