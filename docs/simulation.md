# Симуляция на карте

Откройте OSM и выберите **Симуляция** в верхней панели. После загрузки
машины начинают двигаться автоматически. Можно поставить воспроизведение
на паузу, перемотать, изменить скорость или нажать **К машинам**.

- **SUMO · новый прогон.** Выберите число машин и нажмите **Запустить**.
  SUMO строит сеть из текущей версии OSM, включая несохранённые правки,
  и моделирует 90 секунд движения с демонстрационным набором маршрутов.
  Режим использует [географический вывод FCD](https://eclipse.dev/sumo/docs/Simulation/Output/FCDOutput.html).
  Нужны `sumo` и `netconvert`: они входят в стандартный Docker-образ проекта.
  Для локального запуска установите `pip install eclipse-sumo==1.21.0`
  в окружение бэкенда или добавьте бинарники SUMO в `PATH`.
- **MATSim · запись.** Загрузите `output_network.xml.gz` и
  `output_events.xml.gz` из одного прогона (подойдут и файлы без gzip).
  Укажите EPSG исходной сети: например, `EPSG:32648` для сети в WGS84 / UTM 48N
  или `EPSG:4326`, если `x` и `y` уже долгота и широта. Можно задать
  начало 120-секундного окна в секундах симуляции. При пустом поле
  окно начинается с первого въезда автомобиля. Положение между
  [событиями на дорожных звеньях](https://matsim.org/files/book/partOne-latest.pdf)
  приблизительное: машина движется между концами звена за записанное время.
- **Webots · запись.** Загрузите CSV с заголовком `time,id,lon,lat,angle`.
  Время в секундах, координаты в WGS84, угол в градусах по часовой стрелке
  от севера. Каждая строка задаёт позицию одной машины; один ID не может
  повторяться в пределах кадра. Можно загружать `.csv.gz`.

## Отчёт о симуляции

После прогона SUMO или загрузки записи MATSim/Webots под плеером появляется
**Отчёт о симуляции**: ключевые показатели и пять самых загруженных дорог.
Кнопки **Excel, PDF, Word, CSV, JSON** скачивают полный отчёт.

Показатели измеряются по траекториям: каждая позиция машины привязывается
к ближайшей дороге OSM (до 20 м, с учётом направления). Поэтому они одинаковы
для всех трёх источников.

| Показатель | Как считается |
|---|---|
| Интенсивность N, авт/ч | машин, проехавших по дороге, × 3600 / T |
| Пропущено Q, авт/ч | машин, съехавших с дороги на следующую, × 3600 / T |
| Пропускная способность P, авт/ч | полосы × норматив полосы по классу × доля зелёного |
| Коэффициент загрузки Z | N / P, уровень обслуживания A–F по ОДМ 218.2.020-2012 |
| Средняя скорость | путь / время по всем машинам |
| Время поездки | от въезда до выезда для машин, покинувших сеть до конца окна |
| Время ожидания | время, потерянное против разрешённой скорости (заторы, светофоры) |
| Время простоя | время со скоростью ниже 0,5 м/с |
| Машин в сети | среднее и максимум за окно |
| Очереди у перекрёстков | стоящие машины в 60 м от узла; длина = машины × 7,5 м |
| Завершённые поездки | машины, исчезнувшие из записи до конца окна |
| Выбросы CO₂ | 110 + 2100 / v г/км в движении и 0,6 г/с на холостом ходу (оценка) |

Отчёт содержит листы «Сводка», «Дороги», «Перекрёстки», «Поездки», «Динамика»
и «Методика». Он хранится до следующего прогона в этом документе.

MATSim и Webots выполняют расчёт вне редактора. Для корректного наложения
откройте ту же дорожную сеть, которую использовали в симуляторе.
Импорт ограничен 20 МиБ на файл, 500 машинами в кадре и 60 000 позициями.

## Как записать траектории из Webots

Пример для геопривязанного мира Webots с `WorldInfo.coordinateSystem "ENU"`,
где X и Y — метры вдоль осей исходной проекции:

1. Скопируйте [webots_trajectory.py](../backend/scripts/webots_trajectory.py)
   в каталог мира `controllers/webots_trajectory/` и установите `pyproj`
   в Python, который запускает Webots.
2. Дайте машинам имена `DEF`, например `CAR1`, и добавьте отдельный
   Robot с `supervisor TRUE` и `controller "webots_trajectory"`.
   В его `controllerArgs` передайте EPSG проекции, координаты точки
   `X=0, Y=0` в этой проекции и имена машин:

   ```text
   controllerArgs [ "--epsg" "32648" "--east" "450000" "--north" "5790000" "CAR1" "CAR2" ]
   ```

   Подставьте координаты вашего мира. Если нос модели направлен не вдоль её
   локальной оси +X, укажите другую ось, например `--axis=-y`.
3. Запустите мир. Контроллер снимет позиции и ориентацию через
   [Webots Supervisor](https://cyberbotics.com/doc/reference/supervisor)
   и запишет `webots-trajectories.csv` в рабочий каталог контроллера.
